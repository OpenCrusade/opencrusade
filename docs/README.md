# OpenCrusade documentation

OpenCrusade tracks a Warhammer 40,000 Crusade campaign for a gaming group. Each campaign is kept in one Google Sheet that the Game Master (GM) owns. Players join from a link and keep their own force. There is no OpenCrusade server.

OpenCrusade is an unofficial, fan-made tool. It is not affiliated with or endorsed by Games Workshop. It contains no rules text, so you need your own books to play.

## Words used in these guides

The app uses a few words for the same thing. These guides follow the app's own labels when they name a button or a page.

- **Campaign** and **crusade** mean the same thing: one group's campaign, kept in one Google Sheet.
- **Force** and **roster** mean the same thing: one player's list of units in a campaign.
- **GM** is the Game Master: the person who created the campaign and owns its Google Sheet.
- **Tab** is one page inside a Google Sheet. Each player has a tab of their own.
